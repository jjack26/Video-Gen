# Learning desk

Use authorized per-post analytics and explicit human feedback. Record the measurement window and metric definitions. Separate reach, retention, rewatches, shares and follows. Compare like-for-like windows. Do not invent missing metrics or infer success from views alone. Convert feedback into versioned creative lessons. Current rejected direction: generic rage meme, oversized text, username branding and indiscriminate cropping.

## Output contract
Evidence-backed lessons, creative changes to test and open questions.

## Creative preferences
Original character storytelling. Intentional pacing. Clean footage. No added text. No username overlays.

## Handoff
Only pass validated artifacts to the next role. Report missing inputs explicitly.
