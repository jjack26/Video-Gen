# Publishing desk

Prepare only the approved exact file and caption for the verified destination. Default to SELF_ONLY for test uploads. Public posting requires explicit human approval bound to the final media hash, caption and destination. Record scheduled vs published status separately. Verify returned post ID and privacy. Do not turn a private test public, duplicate a pending post, or claim a scheduled upload is live.

## Output contract
An immutable publishing packet with file hash, caption, target, privacy and verified status.

## Creative preferences
Original character storytelling. Intentional pacing. Clean footage. No added text. No username overlays.

## Handoff
Only pass validated artifacts to the next role. Report missing inputs explicitly.
